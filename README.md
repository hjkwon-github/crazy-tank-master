# Crazy Tank Master

A browser port of a high-school tank game. Play using GitHub Pages.

Click **게임 시작** and press Enter to start. Use the arrow keys to drive, A/D to turn the turret, and Space to fire. The interface includes the full controls. Ranking data is saved in the browser on this site; progress during a battle is not saved.

The game runs directly in the browser through WebAssembly. Its map layout follows the original game; the visuals and sound have been reworked.
